## Findings

### F1: Bugbot Candidate→Promotion Gate
- Source: Cursor Blog
- Summary: Bugbot evaluates candidate rules against live PRs before promoting to active. Rules with persistent negative feedback auto-disable. 78.13% resolution rate on 110K+ repos.
- Gap: Our patterns go count>=3 → direct auto-patch with no intermediate validation. No automatic disabling on negative feedback.
- Severity: P1
- Proposal: proposals/2026-05-04_Candidate-Promotion-Gate.md ✅

### F2: Darwin Godel Machine Archive + Evolution
- Source: Semantic Scholar
- Summary: DGM maintains an archive of coding agents, samples + mutates them to discover improved variants. 20%→50% on SWE-bench. 81 citations.
- Gap: Our pattern archive is passive (just stores). No mutation or crossover between patterns/SOPs.
- Severity: P1
- Proposal: proposals/2026-05-04_Archive-Evolution-Mutation.md ✅

### F3: SEW Workflow Auto-Optimization
- Source: Semantic Scholar
- Summary: SEW automatically evolves multi-agent workflow topology and prompts. +12% on LiveCodeBench vs backbone LLM.
- Gap: Our evolution is at the rule/output level, not at the workflow level. We don't auto-optimize execution sequences.
- Severity: P1
- Proposal: proposals/2026-05-04_Workflow-Auto-Optimization.md ✅

### F4: Real-time RL from Production (logged, no proposal)
- Source: Cursor Blog
- Summary: 5-hour RL training loop using production inference. +2.28% edit persistence, -3.13% dissatisfaction.
- Severity: P2 — model-level training out of scope
- Proposal: none

### Findings (Round 2)

#### F5: Self-Supervised Learning from User Feedback

- **Source:** OpenAI Codex (via WebSearch), Cursor Bugbot (previous scan)
- **Summary:** OpenAI Codex self-improves by monitoring its own training runs and processing user feedback to decide what to build next. Cursor's Bugbot achieves 78% resolution rate by converting PR feedback into reusable rules.
- **Gap:** Our evolution is purely introspective (post-session logs → pattern detection). No mechanism to capture implicit user feedback (corrections, interruptions, retries) during a session.
- **Severity:** P1
- **Proposal:** `proposals/2026-05-04_Self-Supervised-Feedback-Loop.md` ✅

#### F6: Autonomous Evolution / Self-Play

- **Source:** Semantic Scholar — RoboPhD
- **Summary:** Autonomous ELO-based evolution (70→1500 lines, 18 iterations). "Evolved Haiku exceeds naive Sonnet" — largest gains on cheaper models.
- **Gap:** Our "进化" pipeline requires manual trigger + human approval. No autonomous background evolution or fitness-based selection.
- **Severity:** P1
- **Proposal:** `proposals/2026-05-04_Autonomous-Evolution-Daemon.md` ✅
