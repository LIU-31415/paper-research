# Outputs

`tags: #outputs #results`

> 调研结果、工作流产出的最终交付件。每个文件以 `YYYY-MM-DD_Topic.md` 命名。

## Convention

```
YYYY-MM-DD_Topic-Name.md

# YYYY-MM-DD: Topic Name
`tags: #tag1 #tag2`
```

## Output vs Topic vs Session

| Layer | Purpose | Example |
|-------|---------|---------|
| `topics/` | 知识提炼（结论、模型、空白） | Three-Hit 模型架构 |
| `outputs/` | 完整交付件（调研报告、方案文档） | 15篇文献验证报告 |
| `sessions/` | 操作流水账 | 今天装了什么、试了什么 |
